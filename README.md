# DynamicArray

首先 是什么动态数组，用来做什么？

动态数组主要提供以下三大核心功能：
功能一：自动扩容与缩容（最核心）
自动扩容：当你往里面添加元素，发现当前内存不够用时，它会在底层自动向系统申请一块更大的新内存（通常是原来的 1.5 倍或 2 倍），把旧数据全部搬过去，然后继续让你存。你完全不需要手动干预。
自动缩容：当你删除了大量元素，导致当前内存利用率很低时，它会自动释放多余的内存，把空间还给系统。

功能二：保持“随机访问”的极速体验
虽然它是“动态”的，但它依然保留了传统数组最大的优点：在内存中是连续存储的。
这意味着，无论数组里有 10 个元素还是 1000 万个元素，你想获取第 5 个元素，它都能通过数学计算瞬间（O(1) 时间复杂度） 找到，不需要像链表那样从头到尾挨个找。

功能三：高效的“尾部”插入和删除
在数组的最末尾添加或删除一个元素，速度极快（均摊时间复杂度为 O(1)）。
(注：如果在数组中间插入或删除，依然需要移动后面的元素，速度较慢，这是所有连续数组的通病。)
